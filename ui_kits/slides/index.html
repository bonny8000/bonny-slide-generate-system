INSIGHT 02

使用者並非不願意，而是沒有足夠的信心

Cross-source synthesis · interviews × usability test × analytics

WHAT WE LEARNED

三個獨立來源都指向同一個現象 —
使用者想要嘗試，但缺乏信任訊號讓他們敢於行動。

8/12 訪談者主動提到「不知道為什麼」；漏斗數據顯示第二步是流失最大斷點；熱區點擊集中在輔助說明區塊。

→ 系統必須在每個推薦旁顯示理由與透明度訊號，而非只是優化排序演算法。

Synthesis · 2024-09 · 3 evidence sources 05 / 08

SOLUTION CONCEPT

在每個推薦旁加上為什麼 — 從不透明到可解釋

As-Is / To-Be · Same task, same data — different framing

AS-IS · 現況
推薦卡片只顯示名稱與圖片
使用者不知道排序依據
第二步流失率 52%
→
TO-BE · 改版後
每張卡片附「為何推薦」一行
透明度標籤顯示資料來源
流失點預估降至 20% 以下
Design proposal · 2024-10 06 / 08
