# linked-circles

## Purpose
Several labeled, overlapping circles inside one enclosing container — parts that connect into a whole.

## Intention & rationale
The job is to **argue continuity** — that these parts are connected, not siloed. Why this form:
- **Overlap = relationship:** because the circles touch/overlap, the audience reads the parts as linked,
  which a row of separate cards can't convey.
- **The single enclosure says "one whole"** — the stadium/container frames the parts as one system (e.g.
  UX·MX·CX·BX → one total experience).
- **One accent for the labels, neutral translucent fills** keep a busy diagram on-palette.

## When to use / When NOT
Use for a continuum, a "total experience," or interlocking concepts. **Not** for discrete comparison (use
cards/`comparison`) or a center-out hub (use `hero-radial`).

## Structure
Optional bridge **chevron** (`--accent`) + eyebrow + centered title. Below: an enclosing stadium/rounded
container holding **3–5 overlapping translucent circles** (neutral `--surface` tints), each with an
`--accent` label + a 1–2 line `--muted` description. Overlap regions imply the relationship.

## Tokens used
canvas, surface (circle fills, translucent), ink/muted (descriptions), accent (labels + bridge chevron).

## Icon use
Optional; usually none. A single accent chevron may mark a section bridge.

## Content rules
3–5 circles, equal size, overlapping within one container; one short label + 1–2 muted lines each. Labels
accent, bodies muted. Best in dark mode but theme-agnostic.

## Do / Don't
- **Do** keep circles equal and overlapping inside one enclosure.
- **Don't** give each circle a different hue or exceed ~5 (overlap becomes unreadable).

## Example
A stadium holding UX·MX·CX·BX overlapping circles, each with an accent label + muted description, under a
"TX Modeling" title (learned from Img18, structure only).
