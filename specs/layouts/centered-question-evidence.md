# centered-question-evidence

## Purpose
Open a section with a framing question, then back it with three parallel pieces of evidence.

## When to use / When NOT
Use for a Background/"is there a gap?" slide that needs to feel like a thesis + proof. **Not** when you
have only one data point (use metric) or a full research story (use research-flow).

## Structure
- **Top, centered:** small eyebrow (`Background`) + a **question headline** + a one-line sub.
- **Below:** three **evidence-cards** in a row, each a *different* evidence type:
  `icon-stat` · `chart` · `logo-row`. Equal width, equal height.

## Tokens used
canvas, surface (cards), ink (question + labels), muted (sub + captions), accent (one figure/keyword).

## Icon use
Optional: a stat icon on card 1; logos on card 3 (one style, see iconography).

## Content rules
Question ≤ 2 lines, centered. Each card = one figure/visual + one caption line. 繁中 primary.

## Do / Don't
Do keep the three cards parallel and balanced. Don't mix three of the same chart; don't overfill cards.

## Example
Centered "is the service enough?" question + 3 cards: 276,499 member stat / participation bar / app-logo
row (Img8).
