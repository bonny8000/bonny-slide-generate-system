# citation-card
## Purpose
Show a research finding with its source.
## When to use / When NOT
Use for desk-research / literature evidence. Not for opinions or quotes (use quote-bubble).
## Structure
`--surface` card: finding (1–2 lines, `--ink`, one keyword `--accent`) + source line (`--muted`, smaller).
## Tokens used
surface, ink, muted, accent (one keyword).
## Icon use
None.
## Content rules
Finding ≤ 2 lines; source = author/study + year. 繁中 finding; source may be Latin.
## Do / Don't
Do keep the source visually subordinate. Don't pack multiple findings into one card.
## Example
"Recalling positive memories eases stress responses." + source line (Img3).
