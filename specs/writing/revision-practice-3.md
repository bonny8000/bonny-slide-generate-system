# 改稿練習：別讓評語取代事情本身

本批實作 44 輪（151 至 194），三批合計 194 輪。各題均為自造情境；真實稿件沒有細節可核對時，不要自行補寫。

## 把結果、感受和判斷分開

**151｜評價作品時，指出動手就能修的那一處。**

- 自造初稿：這份作品不夠好。
- 改寫：把摺頁合起來，店名剛好壓在摺痕上。我想把它往左挪半個字。
- 換情境：食譜寫「湯太淡」還能再嚐；寫「我不會煮」卻找不到下手處。

**152｜把對自己的判決，縮回眼前的一道題。**

- 自造初稿：我不適合做企畫。
- 改寫：我不是想不出企畫，是一直說不清楚這場講座要邀誰來。
- 換情境：口譯：我聽懂了問題，卻沒聽清楚人名。要補的是人名，不是整句重來。

**153｜區分還沒成交和沒有收穫。**

- 自造初稿：這趟出差沒有成果。
- 改寫：這趟沒接到訂單，倒是弄清楚買方的貨架只有二十公分深，下次不用再帶大罐樣品。
- 換情境：看屋：沒租成，但確定床架進不了那棟樓的電梯。未成交也可能多知道一件事。

**155｜說新版清楚，讓讀者能在兩版上做同一件事。**

- 自造初稿：這個畫面需要更清楚。
- 改寫：以前要打開三筆訂單才找得到還沒寄的那筆，現在看清單上的「待出貨」就行。
- 換情境：班表：同樣找週五晚班，新版從列名就看得出交班時間。別拿不同任務比快慢。

**157｜建議的好處若是讓人敢試，別說成能保證成功。**

- 自造初稿：他給的建議很好。
- 改寫：他叫我先印一張，不必一次印一百張。我這才敢把兩種紙都拿來試。
- 換情境：試教：先講給一位同事聽，能提早發現哪句拗口，不保證全班都聽懂。

**159｜回訪要找第一次看不到的東西。**

- 自造初稿：那次回訪很有價值。
- 改寫：交件那天只看見他會開檔；一週後回訪，他已經在空白欄加了自己的交班記號。
- 換情境：教課：當堂會照範例打結，隔週才看得出學生會拿那個結來綁什麼。

**160｜並列感受與行為時，別把並存硬寫成因果。**

- 自造初稿：壓力讓我好幾天都不開心。
- 改寫：等評選那幾天，我心裡一直懸著；每天還是照常把隔天要用的材料分好。
- 換情境：搬家：我捨不得舊房子，也開始挑新窗簾。準備下一步不代表難過已經消失。

**162｜寫「反應大」之前，先核對旁觀者和當事人接收到的是不是同一個訊號。**

- 自造初稿：她最近對事情反應很大。
- 改寫：我只聽到提示音，她卻認得那是去年每天半夜都響的故障警報。
- 換情境：工作坊：我把倒數當提醒，學員以為時間一到檔案就會清空。別用脾氣解釋資訊差。

**163｜挫折若來自規則，寫出規則，不責怪測試者。**

- 自造初稿：這次測試讓我很挫折。
- 改寫：我把情境演完，才知道評分只看前兩分鐘；後面的處理連被討論的機會都沒有。
- 換情境：投件：插畫通過評選，卻因紙張不符退件；別寫成畫得不好。

**165｜不要用安慰否認影響，區分聽見一句話和得照著做。**

- 自造初稿：不用太在意他怎麼說。
- 改寫：他那句「你講太慢」我也聽見了。先看後排有沒有跟上，再決定下一段要不要加快。
- 換情境：選衣：同事不喜歡這個顏色，不等於值班背心在雨裡不夠醒目。回到用途判斷。

**172｜紀念一刻，先確認它對誰重要，別只替得獎的人記日子。**

- 自造初稿：這是值得紀念的時刻。
- 改寫：發表會那晚最想留的，是女兒念完稿，把講台讓給下一個孩子後，轉身朝自己位子笑的那一下。
- 換情境：結業：父親拍下的不是證書，是孩子第一次自己把樂器收好。意義由視角決定。

**173｜比較兩人進度時，把影響速度的條件寫在旁邊。**

- 自造初稿：我的進步沒有大家快。
- 改寫：同學每天能到木工室，我只排得到週六；我想比的是這週和上週的榫頭合不合，不是誰先做完。
- 換情境：交稿：新稿要先核訪談，重刊稿不用；別只並列完成天數。

**179｜團體檢討不代替所有人發言，先寫自己的疏漏。**

- 自造初稿：大家都從這場雨學到了教訓。
- 改寫：雨一下我才看見，畫動線時只顧作品不淋濕，沒留觀眾收傘的地方。
- 換情境：工作坊：我備了投影片的離線檔，卻沒備學員要填的紙本。不聲稱全組都學到同一課。

**180｜改變看法要交代原本的預期、實際差距和下一次怎麼驗。**

- 自造初稿：改變想法很不容易。
- 改寫：我以為報到要加人，計時才發現大家卡在找姓氏。下回先把名單分欄，再看隊伍有沒有變短。
- 換情境：教學：原以為題目難，學生卻是在抄題上花時間；下次印好題本再比。

**183｜了解一個人，要標明是他說的還是自己觀察到的。**

- 自造初稿：我現在更了解他了。
- 改寫：他說最怕的不是寫不出來，而是交出去後沒人回。這才讓我懂他為什麼每次都先問截稿後的流程。
- 換情境：訪談：她說不怕轉車，怕的是月台沒電梯。不要把需求改寫成「她不愛搭車」。

**186｜達成某一標準之後，不妨讓人物提出那個標準答不了的問題。**

- 自造初稿：我們有不同的成功標準。
- 改寫：訂單接滿是店長眼裡的成功；對已經連三週沒休息的我，下一個問題是：能不能留一天不接單？
- 換情境：升遷：升上主管解答了職等，卻沒解答她還想不想每天畫圖。第二個問題不是否定第一個成果。

**189｜寫辛苦時，把能扛的部分和需要人接住的部分分開。**

- 自造初稿：這條路走得很辛苦。
- 改寫：接了幾天申訴電話，我還能把案子交代清楚，回家卻不想再聽鈴聲。週末我跟同事換了半天班。
- 換情境：照顧家人：我能自己備餐，但回診那天需要有人幫忙接孩子。別把受苦寫成必要資格。

**190｜眼前有解法就說眼前，不必替之後每種狀況打包票。**

- 自造初稿：我已經找到問題的答案。
- 改寫：我找到這箱為什麼退回來了：巷名少了一個字。其他退件還要逐張看，不能一起改。
- 換情境：做麵包：今天這盤底焦是烤盤放太低，上次沒發起來不一定是同一個原因。

## 從抽象勸告改到眼前做得到的事

**154｜把抗拒拆成改動後要重做的事。**

- 自造初稿：我很難接受改期。
- 改寫：我不是不能改星期五，是阿姨已請好週四的假，車也訂好了。
- 換情境：修稿：要換圖可以，但圖說已經錄了音，得把重錄時間算進去。

**156｜「自己的聲音」是什麼，不妨寫成沒人評分時還想做的事。**

- 自造初稿：先聽聽自己的聲音。
- 改寫：先把徵件簡章收起來。要是這幅畫不送比賽，你還想留下哪個顏色？
- 換情境：挑課：不必放進作品集的話，你最想把哪個原型做完？問句要容得下不同答案。

**161｜目標和執行依先後寫，不必把兩種考量演成對立。**

- 自造初稿：我們做了一個艱難的決定。
- 改寫：我們先決定週末照常開店，再從那天往回排，把來不及修的二樓暫時關起來。
- 換情境：校刊：先定出刊日，再排截稿與校對。不是在速度和品質之間選邊。

**164｜先交代專門角色的任務，再說人物做得好在哪裡。**

- 自造初稿：老師把重點說清楚了。
- 改寫：今天老師只負責聽節奏。她敲了兩下桌面，我才聽出自己把逗點和句點停得一樣長。
- 換情境：校稿：核價的人只看金額，他圈出兩欄稅額不一致。分工解釋為什麼看得出來。

**166｜拿別人的經驗作參照時，說清楚不可照搬之處。**

- 自造初稿：我需要換一種方式想事情。
- 改寫：學姊能提早到場試音，我下班才趕得到；我能借的是她把試音句先錄好的辦法。
- 換情境：備餐：隔壁有大冰箱，我沒有；能照做的是先寫好每道菜的備料順序。

**168｜討論分歧時，把爭論變成雙方都能回答的問題。**

- 自造初稿：面對分歧要多溝通。
- 改寫：先不爭要不要加椅子。先說昨天哪一段有人站著等，再看多放兩張會不會擋住推車。
- 換情境：排課：先找哪兩堂非用同一間教室不可，再談誰換時段。問題要比原來的爭執小。

**169｜指導者可幫人拆開見聞與解讀，而非替人宣布正解。**

- 自造初稿：他是個很好的指導者。
- 改寫：我說委員不喜歡提案。老師問：「他說了哪一句？哪一部分是你猜的？」
- 換情境：訪談：參與者把畫面關了，是看得見的動作；他嫌麻煩，還得問。換到研究紀錄仍適用。

**170｜忙完不一定靠硬撐，交代哪段忙碌被人有意截斷。**

- 自造初稿：我們把忙亂的日子熬過去了。
- 改寫：出刊那週，我們把每天最後一校定在九點；之後發現的錯字進隔天清單，不再全組守信箱。
- 換情境：值班：交給夜班的案件有編號，白班才不必回家繼續盯訊息。休息有交接條件。

**171｜說「別想」不如劃出今天做到哪裡就停。**

- 自造初稿：不要總想著做不到的事。
- 改寫：今天沒法重搭整座展架，就先量門寬，把搬不進去的那截標出來。
- 換情境：寫履歷：今晚先核對兩份職稱，推薦信明天再問。一個收得住的動作比安慰更好用。

**174｜方向說得太大，就落到日程上哪一段願意改。**

- 自造初稿：有人提醒我別忘記初衷。
- 改寫：辦讀書會本來是想聽大家說話。我把下一場的開場簡報砍成三張，多留一輪讓新來的人講。
- 換情境：共食：本來是想陪長輩吃飯，便把切菜提早，不讓主人整晚留在廚房。

**175｜圖表若有一項特別基本卻不能省，明說它為什麼要留。**

- 自造初稿：這張圖告訴了我們很多。
- 改寫：這張值班圖保留了空白班次。拿掉空白列，就看不出週六下午其實沒有人接電話。
- 換情境：預算表：保留零元項目，才能區分「已確認免費」和「還沒詢價」。

**176｜暫停決定不是拖延，寫清楚暫停期間要做什麼。**

- 自造初稿：做決定前不要慌張。
- 改寫：先別選印量。把兩家估價單的紙張規格排在一起，確定是同一種紙再比價。
- 換情境：選教室：先走一遍電梯到門口，不靠照片判斷輪椅過不過得去。

**177｜資源說明既要讓人知道何時可用，也要讓人知道不用時可以離開。**

- 自造初稿：我們希望大家善用資源。
- 改寫：交件前需要安靜校對，可以借小會議室；校完就還鑰匙，不必占滿整個時段。
- 換情境：諮詢：只想查費用可直接看價目表，不必為此預約整場。選項不是義務。

**181｜交代哪個方法後來自己也能重做，會談的幫助才不只停在當下。**

- 自造初稿：這次的會談對我很有幫助。
- 改寫：談完後我帶走一個問法：這週哪件事不用等別人就能先做？隔週卡稿時，我又拿它來問自己。
- 換情境：學攝影：老師帶我對過一次窗邊和燈下的白紙，回家後我能自己查偏色。

**182｜取捨先界定任務，不把能力限制寫成人的價值。**

- 自造初稿：想做好就要有所取捨。
- 改寫：這場我能把訪談剪清楚，卻沒時間另外配樂。我選擇留下完整回答，不用音樂填滿每個停頓。
- 換情境：翻譯：時間只夠先核對專有名詞，押韻留到下一版。這是本次取捨，不是自評好壞。

**187｜提醒若能導向新試法，就不必把失誤寫成恩賜。**

- 自造初稿：失誤是重要的提醒。
- 改寫：上次把小包裝秤錯了。這回我把空盒放上秤先歸零，另外留一盒核對淨重。
- 換情境：採訪：收音太遠，下一次先戴耳機試聽；不必感謝那段報廢的錄音。

**188｜練習的起點可以很小，但要看得出怎樣算真的做過。**

- 自造初稿：從今天起我會好好練習。
- 改寫：今天只念第一段，錄下來聽一次；哪句一口氣念不完，就先在那裡畫一道線。
- 換情境：學做帳：先拿昨天的一張收據試登，再核對餘額。不拿決心大小當成果。

**191｜寫「再試」要分清眼前該收拾的事和事後才適合談的事。**

- 自造初稿：她還是想再試試。
- 改寫：水還在滴，她先把畫搬離窗邊。等地板乾了，再談下次展架要往哪裡移。
- 換情境：主持：投影熄了先讓聽眾翻到講義，散場後再查誰改了設定。處理時序不能倒過來。

**194｜同一句鼓勵不一定適用所有時刻；先分清讀者正在等、正在做，還是已做完。**

- 自造初稿：不要忘了給自己一點空間。
- 改寫：寄出稿子後，不用再盯著附件找錯字。先把寄出的版本留好，等編輯回信再動。
- 換情境：等取號時先備妥證件；輪到你就把證件交給櫃員。把同一句「別緊張」換成各時刻用得上的提醒。

## 用取捨、場景和動作收尾

**158｜領悟用一個選擇收尾，比宣告「找到方向」更明白。**

- 自造初稿：我終於知道自己想要什麼。
- 改寫：兩個案子的酬勞差不多，我選了可以自己去現場訪談的那一個。
- 換情境：選旅館：她最後訂了有廚房的房間，想留一晚和孩子煮飯。偏好從選擇浮現。

**167｜讓前一次的做法在新場景下再出現，讀者自己看得出改變。**

- 自造初稿：今年的聚會很不一樣。
- 改寫：往年一到合照，全家就催外婆站起來。今年我們先把椅子搬到窗邊，再往她身邊排。
- 換情境：導覽：上回全團停著等慢走的人，這次把解說點排在有長椅的路段。改變落在安排裡。

**178｜找回節奏若靠他人照見盲點，別寫成全靠自己頓悟。**

- 自造初稿：她慢慢找回自己的步調。
- 改寫：我總以為她嫌自己畫得慢。她把工作簿攤給同學看，才發現時間都花在重找色號；現在調完色就記。
- 換情境：出貨：同事陪我走一趟，才發現我每天重複兩次核對同一欄。觀察者也有作用。

**184｜長程目標可從「到了之後還要做什麼」倒推準備。**

- 自造初稿：出發前做好準備很重要。
- 改寫：火車到站不是就到民宿了。最後那段上坡要推行李，我把小輪箱換成背包。
- 換情境：交件：上傳完還要讓同事能接手編修，所以除了成品，也附上原始檔。

**185｜對未來的讀者說話，先給他一個適合讀這段話的時刻。**

- 自造初稿：這是一份很溫暖的支持。
- 改寫：等你把第一批貨寄出去，如果忽然不知道接下來該忙什麼，就拆開這封信。你不用今天就決定要開第二家店。
- 換情境：寫給新生：等第一個週末宿舍安靜下來，想找人吃飯時，再看看冰箱門上的共餐表。支持有時機。

**192｜視角改變，挑一個位置變了就能看見的細節。**

- 自造初稿：這個經驗改變我的看法。
- 改寫：我一直站在台上嫌海報的箭頭太大。走到入口，前面隔著三排人，我才發現只剩那支箭頭露在外面。
- 換情境：校對招牌：坐在店裡嫌字粗，隔著馬路才看清細筆畫都被車燈吃掉。不是憑感動改觀。

**193｜結尾用一個之後還會做的動作，讓經驗留在生活裡。**
