# Writing — how the words on a slide are chosen (繁中)

The rules for Taiwan Traditional Chinese copy, organised by **what the writer is deciding**, not by
where a rule was first observed. A rule about how a condition sits in a sentence governs a slide
caption exactly as it governs any other text, so nothing here is filed by channel or by source.

The always-read layer is `../foundations/plain-language.md`. It names the handful of checks every
title and caption must pass and tells you which file below to open for the slide in hand.

| read this | it decides |
|---|---|
| `slide-copy.md` | **start here** — every kind of text on a slide (headline, subhead, numbers, captions, cards and chips, flows and timelines, quotes, product claims, on-screen interface copy, the English line, speaker notes) and which rules govern it |
| `intent.md` | what the text promises, asks for, and how certain it is: order of information, conditions and commitments, 預計/可望/將/已, who said so |
| `wording.md` | word choice: one name per thing, numbers and measure words, verbs that match what actually happens, small adverbs (才/就, 還/仍, 只), scope and reference |
| `sentences.md` | sentence build: length and breaks, who does which step, where times and conditions go, parallels and exceptions, connectives |
| `titles-and-body.md` | titles, subtitles, openings, paragraphs, endings, titles on charts |
| `translation.md` | turning foreign-language source into Chinese: reordering, subjects, scope words, time, certainty, interface strings |
| `taiwan-usage.md` | Taiwan terms vs mainland terms, interface glossary, register ladder, characters, punctuation, numbers and dates |
| `ui-components.md` | interface copy by component, for mock screens and proposed UI: buttons, confirmations, errors, empty states, permissions, settings, toasts, variables |
| `drafting-habits.md` | the scan after drafting: stock openings, filler verbs, formula sentences, translationese, each with a question to ask and a fix |
| `revision-pairs.md`, `revision-practice-2.md`, `revision-practice-3.md` | worked before/after examples; open when a rule needs a model sentence (people and service text · research notes, handovers, results · version comparisons, follow-ups) |

The dimension files are refreshed from the writing skill with `scripts/sync_writing.py`; edit rules
there, not here. `slide-copy.md` and this index belong to the slide system.
