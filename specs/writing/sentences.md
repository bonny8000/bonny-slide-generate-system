# 句子組織與長短

## 長短與斷句

- **短句總結，長句帶出內文。** 一段話既要給重點又要解釋，用短句點出重點，再用較長的句子展開原因、條件或關係。讀者只需要結果時，短句就收住。
- **相連的資訊讓它一起讀完。** 條件和建議、原因和結果拆成兩句，讀者得自己接回去。聊天裡，「今晚要排版的話，先用文字就好」一口氣讀完；拆成兩則訊息，第二則讀起來像命令。
- **拆句時，斷句的位置和下一句的開頭一起決定。** 前句介紹一項規定，下一句用「這項規定」接它的影響。前句談了兩項，下一句就帶回能辨認的名稱。朗讀一次，聽到這裡能不能立刻知道在說哪一項。
- **同一句可以交代結果和後續，只要各自的責任清楚。** 拆開長句時，檢查「誰通知」「誰要等」是否還跟著相應的動詞。兩個動作關係緊密、讀一次就知道各由誰做，逗號已經夠用。
- **看兩個分句在回答什麼。** 同一個排程裡，一項已安排、另一項還沒排，可以用逗號並說，兩邊各寫清楚是哪一項。下一段換成另一個請求、期限或例外，另起一句；聊天也可以換行，讓對方看得出要回哪一件事。
- **試讀時，注意哪裡可能接錯。** 「周一」如果只管初稿，就讓它貼著「寄初稿」，後半句點名「定稿」。合句後，如果同一個「如果」「才」可能管到兩種動作，就重寫條件，必要時分句。
- **接連發生的事放進各自的短句。** 敘事從眼前的細節切到今天的變化，另起一句，讀者自然聽出時間轉換。
- **一批東西有兩種結果時，短句也要交代兩邊。** 「已匯出 48 筆，略過 2 筆」；理由會影響下一步時，再補一句。只寫「完成」會讓人以為整批成功。
- **後果多時，一句說會變什麼，另一句說會留什麼。** 確認畫面尤其適用。只剩一行空間，優先留會影響決定的後果。
- **縮成一行時，保留會改變判斷的詞。** 「週四預計送審」可以省主詞和連接詞。「預計」和「送審」各交代一件讀者需要知道的事，刪掉任一個都可能讓人誤讀。
- **縮短提示時，把旁邊的按鈕一起讀。** 按鈕已說明下一步，提示只寫當前狀態。有兩個相近的操作、或按鈕不在旁邊時，在提示裡再叫一次要按的名稱。
- **跨過界線就換做法時，重複同一個時間。** 「可以等到六點半，過了六點半就改天」比「再晚一點就改天」容易照做。

## 誰做哪一步

- **交接要讓下一個人知道何時接手。** 「編輯確認頁碼後，在校樣上簽名；印務看到簽名就送印。」如果只知道兩人各自做過什麼，先確認他們憑什麼訊號接手。

- **操作說明從動詞起筆，換人做時補回主詞。** 「上傳清單，系統約 10 分鐘後寄信通知。」前半省略「你」，後半點出「系統」，讀者就知道哪一步要做、哪一步要等。
- **從一方的行動轉到另一方的看法時，讓句子辨認得出是誰。** 一段裡有人做事、有人評論，每次換人都點名。
- **東西的限制和人的責任分開寫。** 張數限制跟著作品走；需要代表提交時，另說由誰送出什麼。
- **主詞沒換就不必重複。** 同一個人接連做幾件事，依發生順序連寫，共用主詞。每個分句都補「你」「我們」「系統」，讀起來像逐句翻譯。

## 時間與條件放哪裡

- **日期緊跟它所指的動作。** 「截至」限定統計時點，「自…起」交代生效日，「開放至」「…前」交代還能行動到何時。同一段有公布日、開始日和截止日時，一個日期配一個動作。
- **相對時間緊貼起算的動作。** 寄出、收到、開啟是不同時刻。「連結自寄出起 24 小時內有效」把起算點放在時效旁邊。先寫「收到後」，讀者會從收到那一刻開始算。
- **條件放回它適用的那一句。** 入場和導覽各有做法：先說入場要不要預約，另一句從「想參加導覽」起筆，再寫怎麼領取。讀者能看出這個步驟只跟其中一種有關。
- **同一場活動分批開放時，先說清楚是同一場。** 先交代場次，再讓每種身分緊跟自己的開放日期。分成兩則發布時，各自保留足以辨認場次的資訊。
- **條件在前，動作在後。** 「符合資格者，可於 3 月 1 日前申請」讓讀者先判斷跟自己有沒有關係。條件很短、動作才是重點時，可以反過來：「請於 3 月 1 日前申請（限設籍本市者）」。

## 並列、例外與對應

- **讓對象和它的結果靠在一起。** 兩組資料順序清楚時，「分別」可以省去重複的動詞。一句同時列出多個人、項目和結果時，改成一個對象配一個短句。
- **並列兩種情況時，點出差異落在哪裡。** 後半句點名第二個對象，用「則」接出它的情況：「平日開放至晚上九點，假日則到六點。」只是補充同一件事時，直接接續。
- **「除了」之後把關係說完。** 多列一項，用「除了…也…」「除了…還…」。交代例外，就點明誰例外、其餘適用什麼：「除身心障礙者外，一律須事先預約。」
- **列舉之前先報數。** 「退款方式二選一：…」「申請分三步」。讀者先知道有幾項，讀到最後一項時知道已經讀完。
- **例子貼著它說明的那個詞。** 「你的行為（例如冒用他人身分、散布垃圾訊息）造成他人損害」讓人知道例子在說「行為」。把「例如…」拖到句尾，讀起來像在舉「損害」的例子。
- **短的限制用括號貼在東西後面。** 「每場限 30 人（含同行者）」「免費停車 2 小時（限當日消費）」。限制有兩句以上，或會影響讀者要不要參加，另成一句。
- **三項以上、彼此平行、讀者要逐項核對時才條列。** 有先後或因果的內容留在句子裡，條列會把關係拆掉。

## 半句和半句怎麼接

| 看到的連接 | 怎麼判斷 |
| --- | --- |
| 因此、所以、隨後 | 後一件事只是接著發生，用時間詞。「因此」多說了一層因果。說不清前者如何造成後者，就用時間詞或直接並列。 |
| 為了、以免、有助於 | 「為了」帶出想達成的事，「以免」帶出想避開的事，「有助於」談可能的作用。把目的寫成效果之前，要有支持效果的資訊。 |
| 也、卻、反而、但 | 加一項並存的情況，用「也」。後半句違背前文引出的預期，才用「卻」「但」。結果朝反方向發展，「反而」才有著落。 |
| 接著、同時、一邊…一邊 | 兩個動作確實重疊才用「同時」。要讀者照做時，這個差別會改變操作方式。 |
| 也就是、例如、像是 | 「也就是」讓人把後半句當成詞義，「例如」只是其中一種情形。舉例不能把整個詞義限縮成那個例子。 |
| 至於、其中、另外 | 「至於」把前面留下的另一個問題接回來。「其中」讓人回頭找前面的整體。下一句的對象不在那個整體裡，就直接點名。 |
| 針對、關於、在…方面 | 「針對」後面要有人在回應什麼。只是宣布一件事，讓那件事直接當主詞。逐項比較時，「在…方面」可以交代這次比的是哪一項。 |
| 透過、藉由 | 後面是工具或管道、會影響讀者去哪裡辦理，就寫清楚：「透過視訊參加」。「透過報名的方式來參加」可以收成「報名參加」。 |
| 不僅…更…、不只…還… | 「更」讓人期待後一層走得比前一層遠。前後只是並列，用「也」。 |
| 如果、若、要是、…的話 | 「若」較正式，「要是」「…的話」較口語。條件很短時可以不用連接詞：「忘記密碼，請點這裡。」 |
| 此外、另外、同時（句首） | 下一句和上一句本來就在談同一件事時，不需要這個詞。要換話題或補一項獨立的資訊時才用。 |

## 修飾語與重複

- **一連串「的」擠在名詞前時，先把人或物叫出來。** 讀者得等到句尾才知道在說誰，就把時間、來歷、隸屬移到後面另成一句。牽涉辨認「哪一位」「哪一份」的修飾語留在原處。
- **「的」能省則省，省了會歧義就留。** 「我們的團隊的目標」寫成「我們團隊的目標」。
- **同一句首重複，看每次新添了什麼。** 固定句首先後帶出不同情景、一步步推遠，重複能讓讀者聽出節奏。幾句只是輪流重述同一件事，併成一句。
- **同一個詞再次出現，是在呼應還是只是沒換。** 幫讀者接回同一個對象的重複要留。同一段裡無意重複的形容詞或開頭，換掉或刪去。
- **念一遍。** 一口氣念不完的句子，找一個可以停的地方。連著三句一樣長、一樣的結構，改其中一句。
