## 看搭配，不做機械替換

同一個詞在台灣可能兩種寫法都存在，各有所指。先讀它修飾什麼、接什麼動詞。

| 詞 | 怎麼分 |
| --- | --- |
| 水準、水平 | 講表現或程度用「水準」：發揮水準、薪資水準。講方向、姿勢、儀器用「水平」：保持水平。 |
| 訊息、資訊、消息 | 一則收發的內容是「訊息」。供人查閱、判斷的內容是「資訊」。某件事剛傳開是「消息」。 |
| 透過、通過 | 引出管道或方法用「透過」：透過 App 預約。有了結果或走過某處用「通過」：通過審查、通過閘門。 |
| 資料、數據 | 泛指內容、檔案、個人資訊用「資料」：個人資料、資料夾、資料庫。統計出來的數字用「數據」：銷售數據。 |
| 檔案、文件 | 電腦裡的 file 是「檔案」。一份有內容的 document 是「文件」。 |
| 使用者、用戶、會員、客戶 | 一般產品寫「使用者」或直接寫「你」。電信、金融常用「用戶」。有註冊身分寫「會員」。有交易關係寫「客戶」。 |
| 帳號、帳戶 | 登入用的是「帳號」。存放金額的是「帳戶」。 |
| 支援、支持 | 技術上能搭配、能處理是「支援」：支援 PDF。態度上贊成是「支持」。 |
| 品質、質量 | 好壞程度是「品質」。「質量」在台灣指物理上的 mass。 |
| 回覆、恢復、復原、還原 | 回訊息是「回覆」。回到正常狀態是「恢復」。取消上一步是「復原」。回到原始設定是「還原」或「重設」。 |
| 列、欄、行 | 表格橫的是「列」，直的是「欄」。文字的一行是「行」。和中國用法相反，譯表格說明時要特別核對。 |
| 專案、項目 | 一個有期程的 project 是「專案」。清單裡的一項 item 是「項目」。 |
| 驗證、認證 | 確認是不是本人、對不對，是「驗證」：身分驗證、實名驗證、驗證碼。由機構發給資格是「認證」：ISO 認證、認證講師。 |
| 儘、盡 | 「儘快」「儘速」「儘量」「儘管」用「儘」。「盡力」「盡頭」「盡情」用「盡」。 |

## 按要表達的意思選詞

| 要讓讀者理解什麼 | 怎麼選 |
| --- | --- |
| 條件成立才有結果 | 「如果」能帶出假設，「只有…才…」表達必要條件，限制放在它管的動作旁 |
| 事情進行到哪裡 | 「還沒排」表示尚未安排，「已經送出」表示送件完成，寫「能不能」之前先確認目前狀態 |
| 讀者有選擇還是有義務 | 可以選用「可以」，一定得做用「必須」，禁止和無法執行也要說清楚 |
| 有多急 | 能給期限就寫期限，「立刻」和「儘快」代表不同的時間要求 |
| 是告知還是請求 | 告知時寫誰會做什麼，請求時用「請」或「麻煩你」帶出具體動作 |
| 要承接別人的期待 | 可先回覆能做到的事，再交代尚未安排的部分，稱呼依雙方關係調整 |

使用者指定機關名稱、用詞或體例時，保留會影響意思的名稱和用語

## 用字

- **裡、著、為、線、群、峰、床、麼。** 不寫「裏、着、爲、綫、羣、峯、牀、麽」。
- **台、臺擇一。** 一般文案寫「台」，公文與部分機關名稱寫「臺」。機關名稱照對方的正式寫法。
- **週不寫周。** 「週末」「每週」「週年」。
- **身分證、身分。** 法規與證件寫「身分」。
- **帳號、帳單、轉帳。** 不寫「賬」。
- **註冊、備註、註明。** 不寫「注」。
- **公布、發布、布置。** 這幾個詞多寫「布」；「佈」也常見，同一份文案擇一。
- **占、佔擇一。** 「佔」較常見。
- **了解、瞭解擇一。** 一般文案多用「了解」。
- **紀錄是名詞，記錄是動詞。** 「留下紀錄」「記錄下來」。
- **計畫、計劃擇一。** 一般文案多用「計畫」。
- **部分。** 不寫「部份」。
- **聯絡、聯繫。** 不寫「連絡」「連繫」。
- **做、作。** 具體動手用「做」：做法、做菜。抽象或成詞用「作」：作業、合作、作為。
- **的、得、地。** 「跑得很快」「慢慢地走」。口語文案裡「地」常寫成「的」，正式文案分開。
- **再、在。** 「再試一次」「正在處理」。

## 標點

- **全形標點。** 中文句子用「，、；：？！」。英文或數字夾在中文句裡，句子的標點仍用全形。
- **引號用「」，引號裡再引用『』。** 不用 “ ”。按鈕、選單名稱也用「」。
- **書名、影片、文章用《》，篇名可用〈〉。**
- **頓號分隔並列的詞，逗號分隔分句。** 「姓名、電話、地址」。
- **刪節號「……」佔兩格，不寫三個句點「...」。** 介面上表示進行中可以用一個「…」。
- **破折號「——」佔兩格，少用。** 補充說明多半可以用逗號、括號或另起一句。
- **【】標示公告類別或欄位名稱。** 「【系統維護】」「【活動時間】」。常見於公告、社群貼文和信件主旨。用了【】，後面就不再加冒號和粗體。
- **括號用全形（）。** 括號裡只有英數時，可以用半形 ()，同一份文案統一。
- **句中的停頓跟著意思走。** 先把一段話照中文說一遍，分清楚哪裡只是稍停、哪裡已經說完。兩個英文陳述句在中文裡可以用一個逗號接起來；遇到新話題或獨立要求，保留清楚的分界。逗號的個數由內容決定。
- **這套系統寫出的中文一律不用句號**　陳述到末字就收住，接著要說另一件事就換行或分段，讓讀者做決定的問題保留問號
- **委婉傳達限制**　需要放輕語氣時，可以依雙方平常的口吻用一個「～」，例如「還沒排定時間喔～」，原本的限制要說清楚，交稿時只呈現寫好的話
- **驚嘆號一則最多一個。** 錯誤訊息和警告不用驚嘆號。
- **中英文之間要不要空一格，全篇統一。** 沿用該產品或組織的既有做法。

## 數字、日期與單位

- **阿拉伯數字寫數量、日期、金額、編號。** 成語、慣用語、概數用國字：「三天兩頭」「兩三個」「一下子」。
- **日期寫「2026 年 11 月 20 日」或「11 月 20 日（週五）」。** 加上星期能幫讀者核對，「（五）」「（週五）」「（星期五）」由短到正式，全篇統一。「11/20」適合空間小的介面。民國年用於公務情境，寫「民國 115 年」。
- **時間寫「下午 3:30」或「15:30」，全篇統一。** 時段用「至」「到」或「–」：「上午 9:00 至下午 5:00」。
- **金額寫「NT$1,200」或「1,200 元」。** 四位數以上加千分位。大數字用「萬」「億」：「3.5 萬人」。
- **「兩」和「二」。** 量詞前多用「兩」：兩個、兩天、兩週。序數、日期、小數用「二」：第二、二月、零點二。
- **折扣寫「8 折」「打 8 折」。** 等於英文的 20% off，翻譯時要換算。
- **範圍寫清楚含不含端點。** 「18 歲以上」含 18 歲，「未滿 18 歲」不含。

## 口吻與語助詞

- **先聽出說話的人要做什麼**　詢問用「嗎」或「呢」，承接期待、委婉提醒時可按對方平常的口吻選語助詞，交代金額、後果與期限時讓事實清楚
- **「喔」是提醒，「哦」是恍然大悟。** 提醒別人寫「記得帶傘喔」。
- **請、麻煩、煩請、敬請。** 「請」適用多數情境。「麻煩你」較口語。「煩請」「敬請」用於正式書信與公告。一句裡一個就夠。
- **謝謝、感謝、謝謝你。** 聊天用「謝謝」「謝啦」，正式用「感謝您」。回應道謝說「不會」「不客氣」。
- **聊天不寫公告腔。** 朋友或同事之間的訊息不需要「您好」開頭、條列和完整主詞。一兩句、先回答。
