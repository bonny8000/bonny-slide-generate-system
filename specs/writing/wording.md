# 字詞使用

改一句話時，先圈出想換的那個詞，問它在這裡交代了什麼。並列的詞各有適用情境，沒有哪個詞一律不能用。

## 名稱與狀態

- **同一件事沿用同一個名稱。** 前面叫「方案」，後面就不要換成「計畫」「專案」。讀者看到新名稱，會以為出現了另一樣東西。介面上尤其如此：按鈕叫「儲存」，提示就寫「儲存後…」。
- **狀態變了，用詞跟著變。** 同一個人從「報名者」變成「錄取者」，同一份文件從「草稿」變成「已送出」。再次提到時先確認身分、狀態或進度有沒有改變。
- **預計、進行中、已完成各有說法。** 「預計週四送審」「審查中」「已通過」是三件事。審稿時特別看有沒有把計畫寫成了事實，或把送出寫成了完成。
- **日常用語和專業名詞涵蓋的範圍可能不同。** 專業名詞較精確時，想一下讀者在哪一步需要知道差別。只需要大概理解，用日常說法；要照著辦理或比對文件，用正式名稱，並在第一次出現時說明它指什麼。

## 數字、量詞與邊界

- **變了多少，還是變成多少？** 「增加五個名額」回答多了幾個，「增至五個名額」回答最後有幾個。新舊差異是重點時，寫「從三個調整為五個」。縮成標題時這個差別要留著。
- **全部、每個，還是一部分？** 「共」交代合計，「各」說明每個對象都有多少，「其中」從剛提過的整體取出一部分。下一句改談另一群人的比例時，把那群人再點明一次，讀者才知道分母換了。
- **量詞說明怎麼計算。** 「人」算的是有多少人，「人次」容許同一人重複計入；「件」「筆」「份」「場」也各有所指。依實際計數方式選詞，縮短時保留單位。
- **沿用那個領域自己的單位和說法。** 列車算「班次」「列次」，活動算「場次」「梯次」，訂單算「筆」。動物園說「照養」，醫院說「就診」，圖書館說「借閱」。讀者會拿你的字去對照現場的告示和票面，換成別的說法反而要多想一步。
- **保留數字的邊界。** 「至少」「以上」包含寫出的數值，「超過」必須比它多，「約」「近」容許浮動，「未滿」不含該數。會影響資格、上限或費用時，確認剛好落在界線上的人算哪一邊。
- **上限跟著單位走。** 寫清楚限制是每人、每件、每次，還是合計。某一項算在上限之內時，把「也算在內」留在數字旁邊。
- **百分比和百分點是兩回事。** 31% 變成 34%，是「高 3 個百分點」。兩組分母不同時，把件數和總數一起標出來。
- **兩個數字都要有名字。** 「28／30」可能是已回收與目標，也可能是分子與母體。寫成「已回收 28 份｜目標 30 份」。完成率用什麼當分母，就在旁邊說。
- **「平均」「中位數」「最高」跟著數字走。** 把「平均等候時間減半」縮成「等候時間減半」，讀者得出的結論就變了。

## 動詞

- **讓真正的動作當動詞。** 「進行申請」「提供協助」「做出調整」可以先試著寫成「申請」「協助」「調整」。重點在方法或工作階段的名稱時，例如「進行田野訪談」「進行第二階段審查」，保留原來的說法。
- **「能」直接接動作。** 寫給要操作的人，「具有辨識功能」可以寫成「能辨識」。後面接的是需要比較的規格或性質時，保留名稱。
- **向、由、替、幫決定誰做事。** 「向家長申請」是請家長受理，「由家長申請」是家長提出，「替家長申請」是有人代辦。刪字時留住角色，表單和操作說明要單獨核對這個字。
- **動詞後的一個字交代結果。** 「讀」是做了，「讀懂」是理解了；「找」可能還在找，「找出」已有發現；「寄」是寄了，「寄到」是對方收到了。只能確認動作時，寫到動作就好。
- **動詞要對得上實際會發生的事。** 「移除」可以只影響清單，「刪除」會讓人以為資料也消失。「上傳」和「送出」是不同步驟時，各用在對應的位置。「取消」是中止進行中的事，「關閉」只是離開畫面。
- **寫這一步能做到的事，不預支下一步的結果。** 按下去只會送件，就寫「送出申請」。之後還要審核，「確認送印」「完成報名」就多承諾了一個結果。
- **把、將讓東西先出現。** 讀者已知道在談哪樣東西，要知道怎麼處理它，寫「把檔案拖到這裡」「將資料移至新帳號」。焦點在誰負責時，先交代人。「將」較正式，「把」較口語，同一份文案擇一。
- **被、遭、獲各帶評價。** 「遭」帶不利意味，「獲」帶正面意味，「被」居中。中性的分類直接寫誰把它列入哪一類，或用「列為」。寫損失、拒絕或破壞時，再看受影響的一方是否該放句首。
- **同一個數字，動詞看的時間不同。** 「拿下」寫取得，「再添」表示原本已有累積，「以…作收」交代整段結束時的總數，「目前累計」表示還在進行。先決定這句話寫的是哪一段時間。
- **上線、登場、推出、開放、開跑、開賣各有主詞。** 功能和服務「上線」，產品「登場」「推出」「開賣」，報名和名額「開放」，活動和優惠「開跑」。公告的標題用「名稱＋這個動詞」就夠：「全新『圖片搜尋』功能上線」。
- **到期、過期、失效、截止看的是不同時刻。** 「到期」是走到約定的那一天：訂閱到期、帳單到期。「過期」是已經過了、不能用了：連結過期、優惠券過期。「失效」是因為某個動作而不能用：改密碼後舊連結失效。「截止」是不再受理：報名截止。
- **好處用正面說。** 「不會錯過任何一則通知」可以寫成「每則通知都收得到」；「別忘了儲存」可以寫成「記得儲存」。警告和限制才用否定：「刪除後無法復原」。
- **請人「確認」時，寫出要確認什麼。** 對方手上有東西卻不知道你要核對哪裡，就寫清楚要看顏色、標籤還是編號。前一句已把問題問完，「幫我確認一下」才讀得懂。

## 副詞與小詞

| 要分辨的差別 | 怎麼選 |
| --- | --- |
| 陸續、先後、持續 | 「陸續」是分批出現，「先後」交代次序，「持續」是同一件事還在進行。幾處據點分批開放，用「陸續開放」。 |
| 尚未、不再、暫不 | 「尚未」只說到目前還沒發生。「不再」表示先前有過、現在停止。「暫不」表示之後可能恢復。確認這項服務的過去和未來，再選詞。 |
| 才、就 | 「等了三天才收到」讓人讀出久，「才三天」把三天說得短，「三天就收到」比預期快。只交代時間，寫「三天後收到」。 |
| 再、又、再度 | 步驟裡，「再」把下一個動作接在前一步之後。敘事裡，「又」讓人知道相似的事重現。 |
| 還、仍、已 | 「部分城市還查不到」會讓人預期日後開放。原意只是交代目前的範圍時，寫「部分城市查不到」。「仍」強調沒變，「已」強調變了。 |
| 不能、無法、不必、不得、請勿 | 先分辨是做不到、可以省略，還是禁止。讀者可以選擇跳過，用「不必」。功能暫時用不了，交代目前狀況和何時恢復。 |
| 可望、預計、將 | 有時程或估算可循，用「預計」。條件漸漸成熟、結果值得期待，用「可望」。改成「將」之前，確認有人能保證這件事會發生。 |
| 照常 | 讓「照常」跟著沒變的那件事。時間不變、地點改了，寫「下午兩點照常開始，地點改到…」。只寫「活動照常舉行」，讀者會以為所有安排都一樣。 |
| 先、就好 | 「可以先用文字」給對方一個選項。「先用文字就好」還表示做到這裡已經足夠。後面仍要補的東西，照原需求交代。 |
| 只、僅 | 讓「只」貼著它限制的那一項。「只會改清單上的名稱」是限縮影響範圍；「只要改名」讀起來是在說條件。 |
| 優先、專屬、限定 | 先讓一群人報名、之後開放其他人，是「優先報名」。「專屬」「限定」表示其他人不能參加。 |
| 也、都、均 | 「也」加一項，「都」「均」表示沒有例外。有例外時不要寫「都」。 |

## 範圍與指稱

- **有廣義和狹義的日常詞，看旁邊有沒有例外。** 「飯」可以指米飯，也可以指整頓晚餐。對方問要不要留晚餐，而你只想留湯，就把主食和湯各自說清楚。
- **省下稱呼之前，數一下可能指誰。** 前一句只提過一家店，「那家」接得上。提過多家，或訊息可能被單獨轉傳時，帶回名稱或足以辨認的特徵。
- **「這」「該」「此」指回前文時，確認只有一個候選。** 前文有兩項規定，下一句的「這項規定」要換成能區分的名稱。
- **你、您、我們擇一到底。** 同一份文案固定一種稱呼。面向一般使用者的產品多用「你」，正式通知、金融、公務多用「您」。稱呼能省就省：「請輸入密碼」已經知道是誰的密碼。
