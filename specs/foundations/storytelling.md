# Storytelling — show the reasoning, not just the result

The most common senior feedback: *"you jumped to the conclusion."* Make the reasoning its own slides,
**before** the conclusion.

## Order a system/decision like this
1. **Method slide** — the numbered steps you followed (`stepflow`: ① enumerate → ② relate → ③ package).
2. **Detail slides** — the **range** (what you listed, framed as range, bilingual handles) and the
   **relationships** (前後 sequence / 相依 dependency / 並行 parallel) — before any conclusion.
3. **Then** the conclusion / packaging. Never put the "final model / three ways" first.

## Mechanisms → one worked example
Show ONE concrete example as a left-to-right flow (thing → trigger → result), ending on an **enlarged
one-line takeaway (32–36px)**. One real example beats an abstract diagram.

## Continuity
Every deep-dive opens with a one-line bridge from the previous slide. Separate major parts with a
`section-cover` (扉頁). Never jump from an overview straight into a sub-topic.
