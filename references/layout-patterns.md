# Layout Patterns

Use these patterns as starting points. Adapt content, but keep the intent/component match.

## 1. Editorial Background

Use for market context or project setup.

Structure:

- Small category label.
- Large left-aligned headline.
- Short explanatory paragraph.
- 1 chart card or 2-3 evidence cards.
- Optional right-side point cards.

Best mode: light.

## 2. Research Evidence Cards

Use for quantified desk research or survey results.

Structure:

- Center or left headline.
- 3 equal cards in one row.
- Each card contains one chart, one metric, and one sentence.
- Full-width key insight band when a conclusion is needed.

Best mode: light; dark only for final result dashboards.

## 3. Interview Quote Cluster

Use for pain points, user review, or interview synthesis.

Structure:

- Small category label.
- 3-5 quote cards or speech bubbles.
- Highlight repeated phrases in accent color.
- Optional avatar/emoji marker for approachable portfolio tone.

Best mode: light for casual review, dark for serious field research.

## 4. Insight Trio

Use for three synthesized insights.

Structure:

- Centered title.
- Three circles/cards in a row.
- Short insight label, one highlighted phrase, one explanation.
- Optional bottom solution sentence connected by dotted lines.

Best mode: dark for high-level insight; light for research report.

## 5. Problem To Opportunity

Use when each pain point maps to a product opportunity.

Structure:

- Three vertical columns.
- Top card: pain or quote.
- Connector arrow or triangle.
- Bottom bar/card: opportunity.

Best mode: light with blue/purple, or dark with teal.

## 6. As-Is / To-Be

Use when explaining improvement.

Structure:

- Two large cards side by side.
- Left: current state in gray or muted style.
- Right: improved state with accent.
- Center arrow.
- Bottom summary band.

Best mode: light for process clarity; dark for solution reveal.

## 7. Phone Mockup Walkthrough

Use for mobile product features or UI improvements.

Structure:

- Large phone mockup as evidence.
- Side annotations using callout dots and dashed lines.
- Keep UI screenshot readable.
- Use 2-3 annotations only.

Best mode: dark when the phone is the hero; light when comparing form details.

## 8. Service Feature Stack

Use for feature lists or client characteristics.

Structure:

- Left title block with a small pill label.
- Right stacked feature rows.
- One row may be dark/accented to show priority.
- Use minimal line icons only if they clarify the feature.

Best mode: light.

## 9. Metric Result Dashboard

Use for achieved outcomes.

Structure:

- Large result headline or short title.
- 2-3 metric cards or charts.
- Big percentage or time reduction.
- Baseline labels and comparison periods.
- Optional next-step band.

Best mode: dark for dramatic result, light for client report.

## 10. Positioning / Behavior Map

Use for user segmentation or market positioning.

Structure:

- Axis chart or Venn/circle overlap on one side.
- Feature list or result interpretation on the other.
- Highlight selected group with accent and dotted outline.

Best mode: light.

## 11. Workflow / Timeline

Use for process, journey, or phased UX work.

Structure:

- Horizontal line with 3-5 stage labels.
- Cards under each stage.
- Dotted connectors only where they explain movement.
- Use gradient-fill cards in dark mode only when representing progress from pain to solution.

Best mode: dark for UX process review; light for operational explanation.

## 12. Portfolio Cover / Section Divider

Use for opening a deck or section.

Structure:

- One strong title.
- One subtitle or project context line.
- Optional 3D object, product mockup, or large visual.
- Keep the slide sparse.

Best mode: light unless the project itself is dark/tech/system themed.

## Composition Rules

- Favor left-weighted or centered editorial layouts.
- Keep margins generous: roughly 80-120px on a 1920 x 1080 canvas.
- Use 3 cards per row as the default; 2 cards for comparison; 4 only for process stages.
- Avoid nested cards inside cards unless showing UI screenshots or quoted evidence.
- Cards may use rounded corners, but keep them professional: `16-32px` radius for soft portfolio references, `8-12px` for sharper report style.
- Never let decorative objects compete with charts or core evidence.
